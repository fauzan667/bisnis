Pertanyaan Umum

Hal-hal yang Sering Ditanyakan

Jawaban transparan seputar kepemilikan kode, metode pembayaran, dan batasan revisi.

Apakah seluruh source code menjadi milik saya?

Ya, 100%. Setelah pelunasan, kami menyerahkan seluruh source code (ZIP atau repository GitHub), struktur database (.sql), dan panduan instalasi. Anda berhak mengembangkannya di masa mendatang tanpa ikatan lisensi pihak ketiga.

Bagaimana sistem pembayaran dan skema DP?

Kami menerapkan sistem DP bertahap (30% - 50%) di awal kesepakatan setelah brief disetujui. Sisa pembayaran hanya dibayarkan setelah Anda memeriksa hasil kerja lewat live demo atau staging dan memastikan program berjalan sesuai brief awal.

Untuk proyek akademik/skripsi, apakah ada pendampingan alur koding?

Tentu ada. Kami mengutamakan edukasi dan bimbingan teknis. Tim kami menyediakan sesi konsultasi via Zoom atau AnyDesk untuk membantu setup di laptop Anda serta menjelaskan relasi tabel database, fungsi penting pada controller, hingga logika rumus yang diterapkan agar Anda siap mempresentasikannya di hadapan dosen penguji.

Berapa kali batas revisi dan bagaimana ketentuannya?

Kami memberikan garansi revisi bebas biaya hingga 3 kali untuk penyesuaian yang masih berada dalam koridor brief awal (misal: perbaikan bug, penyesuaian tata letak, atau ubah field database). Jika ada penambahan fitur besar di luar brief awal, kami akan diskusikan estimasi biaya tambahannya secara transparan.
